▣ SM / Remote Hardware

Host hardware from THIS computer

Adapters normally use devices plugged into the ECH server. This page lets the hardware live here instead: your browser opens the device and bridges raw bytes/audio to the server over WebSocket. The matching server adapter must be configured with transport: browser (MeshCore, Meshtastic) or input_device: browser (CW/RTTY/PSK31), using the adapter name you enter below. Keep this tab open — closing it disconnects the adapter.

📡 MeshCore node via Web Serial

A MeshCore companion radio on this computer's USB port becomes the server's MeshCore adapter.


Not connected
Requires Chrome/Edge over HTTPS (Web Serial). Pick the MeshCore node's port in the browser prompt (115200 baud is applied automatically).

📻 Meshtastic node via Web Serial

A Meshtastic radio on this computer's USB port becomes the server's Meshtastic adapter. Requires the matching adapter's config to set transport: browser.


Not connected
Requires Chrome/Edge over HTTPS (Web Serial). Pick the Meshtastic node's port in the browser prompt (115200 baud is applied automatically).

🎛️ CAT radio control via Web Serial

Read live frequency/mode from a radio connected to this computer's USB port (Icom CI-V or Kenwood/Elecraft text CAT) and share it with the whole ECH server — Ham Log and other pages auto-fill from it the same way they would from a server-side rigctld connection. This is read-only: setting freq/mode/PTT from other pages still requires rigctld on the server.


Not connected
Requires Chrome/Edge over HTTPS (Web Serial). Firefox is not supported. DigiRig Mobile users: pick the protocol/baud for your actual radio above — DigiRig is a USB CAT/audio passthrough, not a rig of its own, so its serial port carries whatever protocol the connected radio speaks.

🎧 Radio audio via Web Audio (CW / RTTY / PSK31)

This computer's audio input (radio speaker/line-out into mic/line-in) feeds the server's audio-mode decoder; decoded text lands in the message feed. TX audio from the server plays out this computer's speakers/line-out into the radio (VOX or CAT PTT on the radio still required).


Not connected
Requires HTTPS (getUserMedia). Audio is resampled to 8 kHz mono float32 in the browser before streaming.
